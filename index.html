Use it in Power BI Desktop

  1. Import the theme: View → Themes → Browse for themes.
  2. Set the background: Format page → Canvas background → Image, transparency 0%, fit "Fit". The image has only shapes and no text: bands, nav button shapes, card tiles, KPI icons and the KPI color stripe. With tiles on, the theme makes visuals transparent so they sit on the tiles.
  3. The heading text, logo, nav buttons, KPI cards, charts and tables in the preview are placeholders. Add your own visuals over the open areas.
  4. Bar width, chart types and table options are preview-only. Set them in Power BI under each visual's Format pane.
  5. Fonts and brand colors are written into the theme JSON. Use fonts Power BI ships with, because other fonts only render where installed.
  6. Tile shadows are drawn into the PNG. Hover effects cannot be stored in an image, so they only show in this preview. In Power BI use each visual's Effects settings or button hover states. Alignment is preview-only, except chart title alignment, which goes into the theme.
  7. The theme JSON also carries your status colors (good, neutral, bad, null), heading and body text colors, brand data colors and fonts.
  8. Landing page: use the landing PNG as the canvas background of page 1. Add text boxes for the heading and description, and a button linking to page 2, over the shapes.
  9. Canvas size: choose the same size in Power BI under Format page, Canvas settings, Type. 16:9 is 1280 × 720.
